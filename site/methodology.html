1. Study design (the paper)

A single reference sample was prepared in one batch (250,000 viable cells per 0.5 ml aliquot), cryopreserved, and distributed to the partners. Design composition (% of viable cells):

PBMC 60%colon 30%

Human PBMC 60% · mouse colon 30% · HEK293T 6% (human, RFP-labelled) · NIH3T3 3% (mouse, GFP-labelled) · MDCK 1% (dog, TurboFP650-labelled). Mixed species allow doublet exclusion; spiked-in lines expose batch/capture bias. Expected species mix per protocol (paper Fig. 1): human 63–95%, mouse 4–34%, dog 1–9%.

13 sc/snRNA-seq protocols (~3,000 cells each; 5 plate-based, 7 microfluidic — 4 droplet, 1 nanowell, 2 integrated fluidic circuit C1HT-small/medium — plus 1 single-nucleus experiment), plus a large Chromium V2 reference (30,807 human + 19,749 mouse cells) used only to define cell types and markers (Table S2), never to score protocols. Downsampling standard: 20,000 reads/cell (lowest first quartile) via the zUMIs downsampling function, plus stepwise 25/50/75% fractions and equal cell numbers. Stratified cell types for human: HEK293T, monocytes, B cells; mouse: secretory and transit-amplifying (TA) colon cells.

2. Input data: accessions, files, formats, quirks

2.1 Where the data live

GSE133549 is a SuperSeries with no files of its own; count matrices live in 15 per-protocol SubSeries (plus GSE141469 for 10X V3), retrieved 2026-10-13 into data/raw/ and processed the same day. Base URL pattern:

https://ftp.ncbi.nlm.nih.gov/geo/series/{PREFIX}nnn/{ACC}/suppl/
# e.g. PREFIX=GSE133, ACC=GSE133540 ; GSE141469 uses PREFIX=GSE141

Each SubSeries ships 4 gzipped TSVs: {ACC}_{PROTO}_human_exp_mat.tsv.gz, …_human_metada.tsv.gz (note the authors' truncation, single "t"), and the mouse pair. This repo processes the human matrices only (largest table per SubSeries, picked automatically — §5.2).

2.2b Mouse track

The same 15 SubSeries ship mouse colon matrices (…_mouse_exp_mat.tsv.gz), prepared with PROCESSED_DIR=data/processed_mouse SPECIES=mouse into an identical per-protocol layout and analysed with config.mouse.yaml (same parameters; output site/data/results_mouse.json + .js fallback). 2.3 Format quirks (load-bearing)

  • No corner cell: the header line holds N barcodes while data lines hold a gene ID + N counts. pandas.read_csv(..., index_col=0) resolves this correctly (index name = first barcode, gene IDs as index); naive usecols=[0] reads mistake the first count column for row names.
  • Gene identifiers are ENSEMBL IDs with versions (e.g. ENSG00000000003.14), not symbols — so the MT-/MT. mitochondrial prefix match finds nothing (§11).
  • Integer UMI/read counts (verified: all values integral) — raw, unnormalised, as the pipeline assumes.
  • Metadata has no cell-type labels. Columns are QC/mapping metrics (nTReads, nExonReads, nIntronReads, nIntergenicReads, nUnmappedReads, nAmbiguityReads, nMultimapReads, nUMIs, nGenes, Species, Library, Donor, nVars, is_cell_control, total_features_by_counts, …). Hence label_coverage = 0 and ARI/NMI/silhouette are skipped until an external data/metadata.csv (index = cell barcode, column celltype) is supplied; the authors' labeller is matchSCore2.

5. Pipeline scripts, in order

0

run.sh — one entry point

setup | download | prepare | inspect | analyse | test | serve. serve runs python -m http.server -d site 8000 (serve site/, never the repo root; never double-click the HTML — file:// blocks data loading).

1

pipeline/download_geo.sh list|get — fetch from NCBI

list prints supplementary files per SubSeries; get ACC… downloads them to data/raw/{ACC}/. Fixed in this repo to skip non-data links (an hhs.gov href used to abort multi-accession downloads under set -euo pipefail).

2

pipeline/prepare_data.py ACC… — raw → processed

Extracts *.tar*, picks the largest table file per SubSeries (always the human matrix here), copies to data/processed/{protocol}{ext} via a hardcoded accession→protocol MAP (GSE133535→10X_2x5K_250K … GSE141469→10X_V3). Prints chosen vs alternative files — verify the choice.

3

pipeline/inspect_data.py — diagnose before analysis

Per file: rows/cols, numeric-column fraction, integer-count check (False ⇒ already normalised ⇒ assumptions break), orientation guess, metadata barcode overlap. Its row-name display misreads corner-less TSVs (shows nan); the analyser is unaffected.

4

pipeline/run_analysis.py [config] — the analysis

Sections §6.1–§6.8: chunked load → QC → equalise → normalise/HVG/PCA → kNN+Louvain → score → results.json (+ auto .js fallback). Preserves previously curated discrepancies across re-runs. Guards: protocols with <50 cells or <100 genes post-QC are skipped into errors, not crashed on.

5

pipeline/qc_distributions.py [results.json] [--dtype float32] — pre-QC distributions

Second chunked pass (chunksize=2000, float64 accumulators) over the same matrices: per-cell genes/UMIs percentiles, genes seen in ≥1/≥3 cells, top-50/200 count shares, top-5 gene IDs. Merged into each protocol's qc_dist (powers Quality Figs. R6–R8), including a ≤1000-cell per-cell sample (cell_sample{genes,umis}) backing the R13 violins. --dtype float32 halves peak chunk memory (≈2× faster on large matrices) with identical rounded outputs; default float64 preserves existing results bit-for-bit.

6

pipeline/similarity.py [results.json] — cross-protocol similarity

Two chunked passes per matrix: (1) per-cell gene counts → QC mask (≥ min_genes) → fixed ≤100-cell sample (seed 0); (2) per-gene sums over QC cells + sampled presence submatrix. Then: gene intersection across protocols (common genes) → mean CP10K per gene → log1p → Pearson matrix; cumulative union genes over 1–100 cells, mean of 3 shuffles. Writes d["similarity"] (+ .js).

7

pipeline/make_synthetic.py + tests/test_pipeline.sh — smoke test

Generates 3 synthetic protocols (1200 genes; depths 4000/1500/700; 400 cells each) into data/synthetic/, runs the analyser with config.synthetic.yaml → site/data/demo.json, asserts 3 protocols and ARI>0.5. Output is never real data; the dashboard's ?demo mode loads it.

6. Analysis internals: formulas and algorithms

6.1 Load

Text matrices stream in 1000-row gene blocks into a CSR cells×genes matrix (float32). 10x folders: mmread(matrix.mtx).T with features.tsv/genes.tsv + barcodes.tsv. Orientation: auto treats input as genes×cells when rows>cols and transposes. Memory-safe: peak ≈ one block (e.g. 1000×80,000 float32 ≈ 320 MB for the largest 10X set).

6.2 QC

Per cell: n_genes = #(X>0), umis = ΣX, mito% = 100·ΣX_mito/max(umis,1) (0 everywhere here — §2.3). Keep (n_genes ≥ 200) & (mito% ≤ 20); then drop genes seen in <3 cells. Medians of the survivors are the reported median_genes/median_umis/median_mito_pct.

6.3 Normalise → HVG → PCA

CP10K: X′ij = Xij · 10⁴ / ΣjXij  →  L = ln(1+X′)  →  top-2000 variance genes  →  z = clip((z−μ)/σ, −10, 10)  →  TruncatedSVD(30, seed 0)

6.4 kNN graph → Louvain

kneighbors_graph(PCs, k=min(15, n−1), include_self=False), symmetrised by element-wise maximum with its transpose, converted with from_scipy_sparse_array, partitioned by louvain_communities(resolution=1.0, seed=0); community index = cluster label; count = n_clusters.

6.5 Equalisation, labels, stability

Each protocol is subsampled (seeded, no replacement) to n_use = min(5000, min QC-pass counts) — currently 1,451 (inDrop is smallest). Reference labels (when present) reindex by barcode; ARI/NMI/silhouette (silhouette on ≤2000 cells) need >50% labelled cells. Stability (always computed): 5× draw 80% of cells, re-embed and re-cluster from counts, ARI vs full-data labels restricted to the subsample; report mean ± SD. t-SNE: ≤1500 cells, perplexity=min(30,(n−1)/3), init="pca", seed 0, coordinates rounded to 2 dp.

6.5b Stored embeddings

For the t-SNE cell subset (t, ≤1500 cells): PCA scatter (P[t,:2] + the full 30-component explained_variance_ratio_), UMAP coordinates (or null), and cellstat (cluster + per-cell genes/umis from the post-QC arrays). These power the Explorer views and the R14/R15 cluster boxes. t-SNE perplexity = min(30, (n−1)/3), init "pca", seed 0.

6.6 Cluster markers

On the equalised cells, log1p(CP10K) values over the top-n_hvg variable genes: per Louvain community, score = (meanin − meanout) × fraction expressing; top 5 kept. The union set (≤5 genes × communities) is stored with per-cluster means/fractions for the dashboard dot plot (Fig. R10). Deterministic — uses no RNG, so equalisation, stability draws and t-SNE are bit-identical with or without this block. Names stay as-matrix (ENSEMBL IDs); pipeline/map_symbols.py adds symbols when resolvable.

6.7 Synthetic data (test only)

4 cell types × 1200 genes; type-signal genes amplified 8×; depths 4000/1500/700 via Poisson sampling; 400 cells/protocol; MT-0…12 synthetic mito genes.

9. Metric definitions and reporting standard

MetricEstimator, range, and reporting
Median genes / countsMedian over QC-pass cells at full depth (paper: 20K reads cell−1 per cell type). Log10 axes; protocols ordered descending. UMI and read-count chemistries estimate distinct quantities.
RetentionQC-pass / input cells (min_genes ≥ 200; mito gate inoperative on ENSEMBL IDs).
ARI / NMI / silhouetteARI ∈ [−1,1] (≈0, chance); NMI ∈ [0,1]; silhouette ∈ [−1,1] (≈ paper ASW). Require >50% labelled cells; silhouette on ≤2,000 cells. Current labels are species-level, so ARI indexes species agreement, not cell-type accuracy.
StabilityMean ± SD (n = 5 seeded 80% re-embeddings/re-clusterings) of ARI(full, subsample). Axis fixed [0.5,1.0]. Precision, not accuracy.
CompositePer-metric min–max over the processed set; arithmetic mean (paper: harmonic mean of 6 at 20K reads — degenerate under few-protocol min–max). Set-relative; rescaling on protocol addition.
Concentration / heterogeneity / evennessTop-50/200 count shares; CV = SD/mean across cells (R22); effective k = exp(Shannon entropy), evenness = H/log k (R23).
Residuals (R21)OLS residual of log10 genes on log10 counts across protocols; + exceeds depth expectation.

Legend standard: every figure states the display, estimator, n, transform, ordering, and error representation. Claims are scoped to the processed set and depth standardisation.

11. Threats to validity and known artefacts

  • Construct. Full-depth medians conflate depth with efficiency (mitigated by R21 residualisation); UMI and read counts mixed; mito gate void on ENSEMBL IDs; Louvain/30-PC/res-1.0 stack differs from Seurat/8-PC/res-0.6; variance HVGs differ from paper; current labels are species-level, so label agreement ≠ cell-type accuracy.
  • Internal. Single master seed (0); 5 stability repeats; min–max composites are set-relative and rescale on protocol addition.
  • External. One batch, two tissues, no 20K-read standardisation — rankings are conditional. Cross-tissue checks (R18–R20) bound, but do not remove, this limit.
  • Artefacts. Species doublets retained in matrix totals; TruncatedSVD RuntimeWarnings are cosmetic (outputs finite and verified); software versions are embedded per run (results.json: environment); paper.mapping shares are null where GEO QC supplements lack read-location columns (P2 omits those protocols), and all JSON output is strictly parseable (no NaN).

11b. Generalizability: more tissues, not more species

Human + mouse is sufficient for protocol benchmarking — the ranking signal comes from protocol chemistry, not species count. For better generalizability, add more tissues / complexities / depths with the same 2 species (e.g. heterogeneous vs homogeneous tissue, high- vs low-RNA-content cells, full depth vs downsampled to 20K reads/cell), not new species.

New species add confounders without changing the ranking: annotation completeness, mito-gene prefixes (mito_prefixes in config.yaml), ortholog mapping, and dissociation bias. Add a species only to test species-mixing doublet detection or cross-species mapping.

Implemented as dashboard tab Generalizability (loads results.json + results_mouse.json jointly; 15 shared protocols): R18 median-genes human-vs-mouse scatter (log–log, Pearson r ≈ 0.84) · R19 human-vs-mouse rank bump (parallel = generalizable) · R20 stability human (dot) vs mouse (square) per protocol.
